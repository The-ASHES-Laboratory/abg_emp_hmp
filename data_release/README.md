NYABG burial-soil 16S rRNA genus-level data bundle (v1.1.0)

Files
- nyabg_genus_counts.tsv: genus-level read counts (SILVA 138 taxonomy, harmonized to the merged NYABG-EMP-HMP genus table used in the analysis), 882 genera x 78 samples (72 burial, 6 control). Column sums equal the genus-level depth in nyabg_sample_metadata.tsv.
- nyabg_sample_metadata.tsv: per-sample metadata and read counts (identical to Additional file 7 of the article).

Raw sequence reads are not included. They are held under managed access for ethical and descendant-community reasons consistent with the CARE principles; requests are handled as described in the Data Availability statement of the article.

Control soils were collected from public parks within a 2-mile radius of the NYABG excavation site in Lower Manhattan.

Code: https://github.com/The-ASHES-Laboratory/abg_emp_hmp (release v1.1.0).
